# phIA

> Projeto de longo prazo para desenvolvimento de Inteligência Artificial,
> jogos e robótica.

## 🧠 Sobre o projeto

O phIA é um projeto pessoal de pesquisa, desenvolvimento e aprendizado
voltado à construção de sistemas de Inteligência Artificial.

O objetivo inicial é compreender os fundamentos da Inteligência Artificial
e desenvolver modelos próprios, evoluindo gradualmente para sistemas mais
complexos.

No futuro, o projeto poderá integrar Inteligência Artificial, desenvolvimento
de jogos e robótica.

## 🎯 Visão

Construir, ao longo do tempo, um ecossistema tecnológico próprio envolvendo:

- Inteligência Artificial
- Machine Learning
- Deep Learning
- Modelos de linguagem
- Visão computacional
- Jogos
- Robótica
- Simulação

## 🧭 Filosofia

O objetivo principal não é obter certificados.

O objetivo é adquirir conhecimento suficiente para:

- compreender os fundamentos;
- implementar algoritmos;
- realizar experimentos;
- analisar resultados;
- construir sistemas próprios;
- entender as limitações das tecnologias utilizadas;
- evoluir continuamente o projeto.

## 🚀 Primeiro objetivo

Desenvolver os fundamentos necessários para construir uma primeira
Inteligência Artificial própria.
