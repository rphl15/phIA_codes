# Visão do phIA

## 1. Conceito

O phIA é um projeto de longo prazo dedicado ao estudo e desenvolvimento
de tecnologias próprias de Inteligência Artificial.

A IA será o primeiro núcleo do projeto.

Posteriormente, o projeto poderá expandir para desenvolvimento de jogos
e robótica.

## 2. Objetivo inicial

O primeiro objetivo é compreender os fundamentos necessários para desenvolver
uma Inteligência Artificial própria.

Não existe prazo definido para conclusão.

O desenvolvimento ocorrerá de forma progressiva.

## 3. Princípios

### Conhecimento antes de abstração

Sempre que possível, os fundamentos serão estudados antes da utilização
de abstrações de alto nível.

### Construção

Conhecimento deverá ser convertido em implementação.

### Experimentação

Hipóteses deverão ser testadas através de experimentos.

### Documentação

Descobertas, erros e decisões deverão ser documentados.

### Evolução

O projeto será desenvolvido incrementalmente.

## 4. Visão futura

O phIA poderá eventualmente integrar:

- IA
- modelos de linguagem
- memória
- visão computacional
- agentes
- jogos
- simulação
- robótica

## 5. Estado atual

Projeto iniciado.

Foco atual:
